GENERATED FROM `src/commands/commands.json` - do not hand-edit this file. The list is the truth; this is a copy. `/rtfm cheatsheet` renders it fresh, `/rtfm check` says whether the copy has fallen behind, and `/rtfm export` downloads a new one. A command is added by editing the list, never by editing this page.

- `/rtfm check` - whether this copy still matches the live list.
