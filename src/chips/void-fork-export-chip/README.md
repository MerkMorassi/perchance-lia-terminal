# Void Fork

Browser port of [voideditor/void](https://github.com/voideditor/void) + best ideas from [void-forks](https://github.com/voideditor/void-forks/).

- Chat: `normal` / `gather` / `agent` (like Void ChatMode)
- `Cmd/Ctrl+K`: quick edit selection (like Void quick edit)
- `Cmd/Ctrl+L`: focus chat (like Void)
- Apply: Fast (SEARCH/REPLACE `<<<<<<< ORIGINAL`) or Slow (full rewrite)
- Checkpoints: review diffs, accept / reject / restore
- Providers: built-in free + any OpenAI-compatible endpoint (Ollama, LM Studio, OpenRouter...)
- Teach Mode explains every change (A-Coder idea). Power Mode lets agent touch many files (NeuralInverse idea).
