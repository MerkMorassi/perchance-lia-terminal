# VOXCONPACK Master Spoken Aliases Catalog
**Protocol:** VOXCONPACK
**Rule:** Spoken Aliases are natural-language inputs that normalize to a single canonical `VOX.<COMMAND>`. Natural language is an interface, NOT an authority model.
