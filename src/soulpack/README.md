# SOULPACK - the core that brings an AI to life

Read whole, in manifest order, at first boot. Re-checked periodically: the startup chip counts these scrolls every waking and says SOUL :: n SCROLLS, CHECKED. A waking with no soul is reported, not hidden.

Adding a scroll = drop the file in + one soul.json entry. No code edits. Nothing here is optional; nothing here is retrieved - it is always in context.
