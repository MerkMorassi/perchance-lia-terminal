# CODY'S RULES - THE AGENT'S OWN LANE GETS A NAME AND A HOME

2026-09-30 - the session he named the agent's standing rules, and the session a home was built for them.

## WHAT HE SAID

He had just read the agent's account of reading the record - the brief, the record's own opening, the
entry explaining the lane - and answered with three words and a colon:

> *"Cody's Rules: Brief first, grep before re-deriving, write every pass down."*

No instruction beyond that. Taken as a designation: the rules ARE those three, they are HIS naming of
them, and they belong in a place a later session will meet - not in a chat window that closes.

## WHAT A RULE IS, HERE

The three are not new behaviour; each was already the way this project was built. What is new is that
they have **a name, a home, and a reason written beside them**, which is the difference between a habit
and something a later session can be measured against:

| rule | the door | the cost it prevents |
| --- | --- | --- |
| **1. BRIEF FIRST** | `/chatlog brief` - two chunk reads whatever the record weighs - then `/chronicle newest`, then the top of `README.md` | a session that reads 5.87 MB whole spends itself on the reading; one that reads none of it re-derives settled ground - and *where a session has been* is not recoverable from the code at all |
| **2. GREP BEFORE RE-DERIVING** | `/chatlog grep`, `/docs search` / `/docs related`, `/renders find`, `/recipe negative`, `/lore`; and `grep` before `read` | a dead end walked again, a measurement guessed at, a ruling relitigated - when the record already holds the words and the date, and an answer with a citation is stronger than a memory of it |
| **3. WRITE EVERY PASS DOWN** | `README.md` (what is true now), `TODO.md` (one `§` per pass), `src/chronicle/` + `chronicle.json` + `src/pack/files.json`, `src/rtfm/` when a command changed | an unwritten pass dies with the chat window - which has already happened once here: the editor refused a 78,797-character message, and the working context was compacted to a handoff |

One honest caveat is written into rule 1 rather than hidden: the brief's `WHERE IT STARTS` currently
prints turn 1 of the *imported* region, not the conversation's first message (the index stops at the seam,
`TODO.md` §1dm), so `show first` is the true beginning until that is fixed.

## WHERE IT LIVES, AND WHY IT IS A FIFTH LANE

`src/cody/README.md` is the file. The lane table (in `src/chronicle/README.md`) already separated four
places so no reader confuses them - hers (the LOREPACK), his manual (the RTFM), the state (README,
TODO), the making (the chronicle) - and this is the fifth: **the maker's.** How the building is done, by
the agent doing it. Nothing here is indexed, retrieved, recalled or handed to LIA; nothing here is a
manual; everything here is public, because it ships.

That last point is the one worth keeping: the rules are public *on purpose*. A rule that a stranger can
read is a rule that a later session cannot quietly reinterpret.

## WHAT WAS THOUGHT

**A named rule is a rule that can be invoked.** "Read the brief first" is advice; "per Cody's Rules" is a
citation, and a session that is about to skip the brief can be asked which rule it is breaking. The name
is the whole point of his phrasing, so the name is what was built.

**This lane is the agent's because the other four all belong to someone else.** Her memory, his manual,
the project's state, the project's making - and none of them is where *how to work here* goes. The
chronicle entry of 2026-09-26 already said it: *"the lane being designed across those messages is mine,
not hers ... this is the memory of the agent that is doing the making, portable across his generators."*
He has now given that lane its first content and its first word.

**Nothing was invented.** The rules are his sentence, split into three and hung on the doors that already
exist; the doors are all already in the module and in the commands; the reasons are the ones this project
has already paid for (the record read whole, the dead ends, the pass that died with a window).
